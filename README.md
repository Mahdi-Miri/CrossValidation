# CrossValidation 
This Python project builds and evaluates a binary classification model using TensorFlow/Keras. It employs Stratified K-Fold cross-validation to assess model performance on synthetic data.

Key Features:

Synthetic data generation using scikit-learn.
Deep learning model implementation with TensorFlow/Keras.
Model evaluation using Stratified K-Fold cross-validation.
Technologies:

TensorFlow/Keras, scikit-learn, NumPy.
Use Case:

Building and evaluating binary classification models with deep learning.
